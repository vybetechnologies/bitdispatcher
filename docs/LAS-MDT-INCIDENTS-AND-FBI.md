# Officer incidents, report drafts, and FBI public notices

MDT's unit-status rail includes **New incident**. An available officer selects an agency call type and priority, enters a location/narrative and can include the unit's reported GPS position. The server creates and assigns the call to the authenticated account's assigned unit under one engine lock. Client-supplied agency, linked call and verification status cannot override the unit binding. Existing staffing checks apply. **Close incident** requires a configured disposition and is limited to the officer's current call; another active unit prevents MDT closure. Dispatch can close multi-unit calls using its existing controls.

The report editor offers **Delete draft** for an author's drafts (administrators may manage any draft). Submitted, approved and returned reports cannot be deleted. Deletion removes the active report and its incident link while retaining attributed ledger history. A delayed autosave cannot recreate a deleted report number. Windows journals creation, notes, closure and draft deletion offline, resolves temporary call/report numbers on reconnect, and retains the existing ownership, conflict and replay checks.

Person search starts a separate FBI public-notice lookup alongside the unchanged local-first/Enformion path. It uses the official `https://api.fbi.gov/wanted/v1/list` endpoint documented at `https://www.fbi.gov/wanted/api`. Only name terms are sent externally; a supplied DOB is used locally to exclude notices with conflicting known DOBs. The upstream title filter may return broad OR matches, so all entered name words must match the title or one alias. Captured/located/deceased results are excluded when explicitly marked. The lookup is bounded to two pages and five seconds, with private short-lived caching and attributed search audits. Failure does not fail or change local/Enformion results.

FBI candidates have their own caution cards and independent MDT voice announcements, including published warning/caution text and an official FBI page link. They are possible public-notice/name matches, not confirmed identity, active warrant or NCIC results. Notices can include missing-person and seeking-information categories; the returned category/classification is shown. Verify the official notice and current status with dispatch. Results are not imported into local person records or used to overwrite employee tags/core safety flags. FBI notices require connectivity; offline local record searches continue to use the protected downloaded records.
